## 업비트 상세

- 일봉 응답의 `candle_date_time_utc` 가 `T00:00:00`, `candle_date_time_kst` 가 `T09:00:00` 이다.
  즉 **업비트 일봉은 UTC 00시(KST 09시) 경계**다.
- 프로젝트 결정은 BTC 하루 = **KST 00시 경계**다. 그래서 일봉 API 를 그대로 쓰면 결정과 어긋난다.
  - 방법 A: 60분봉을 받아서 KST 00시 기준으로 직접 집계(시가=첫 봉 시가, 고가/저가=최대/최소, 종가=마지막 봉 종가, 거래량 합).
    3년치 60분봉은 약 26,300개, 요청당 200개라 초기 적재에 약 132회 호출. 이후는 하루 1~2회 호출.
  - 방법 B: 업비트 일봉(KST 09시 경계)을 그대로 쓰고 화면에 기준을 표기.
- 요청 예: `https://api.upbit.com/v1/candles/days?market=KRW-BTC&count=200&to=2023-11-15T00:00:00Z`
